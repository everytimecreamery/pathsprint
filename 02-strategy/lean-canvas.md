# Phase 4: Lean Canvas

| Canvas Block | Details |
| :--- | :--- |
| **Problem** | 45% fresh grads unemployable; severe English hesitation; 300+ resumes sent with 0 recruiter callbacks. |
| **Customer Segments** | Tier-2/3 undergrads (3rd & final year) and unplaced fresh graduates across Tech, Data, Finance, and Marketing. |
| **Unique Value Prop** | "From College Hesitation to Corporate Confidence" — ATS resume, speaking pods, and projects for < ₹1,500. |
| **Solution** | 30-Day Cohort Sprint: 4-student practice pods, async Loom video audits, and capstone mock HR interviews. |
| **Channels** | Free Sunday Masterclasses, LinkedIn Resume Teardowns, Campus Ambassador referral loops (₹200/peer). |
| **Revenue Streams** | Tier 1: Async Audit (₹499) · Tier 2: 30-Day Sprint (₹1,499) · Tier 3: Sprint + Mentor Call (₹2,499). |
| **Cost Structure** | Zoom/Google Meet, Notion, Canva, Loom, Razorpay (~2%). Total fixed overhead < ₹3,550/month. |
| **Key Metrics** | Interview Shortlist Rate (% getting callbacks within 30 days), Pod Attendance (≥80%), Student NPS (≥60). |
| **Unfair Advantage** | Vernacular-friendly peer pods, radical transparency, zero predatory loans or deceptive placement promises. |
